== Approved Tags

Tags are classifications, never technology versions. Technology metadata belongs in
`properties` (see the modelling standards). The validation pipeline rejects any
software system tag not listed below.

Approved element tags:

* EnterpriseSystem
* CriticalSystem
* Platform
* VendorHosted
* SaaS

To propose a new tag, raise a merge request against this file. Changes require
Architecture Practice approval (see CODEOWNERS).
