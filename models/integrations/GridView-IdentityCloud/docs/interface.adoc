== Interface: GridView -> IdentityCloud

[cols="1,3"]
|===
| Purpose | User authentication and single sign-on for GridView.
| Source System | GridView
| Target System | IdentityCloud
| Data Classification | Confidential (identity data)
| Authentication Method | OIDC authorization code flow with PKCE
| Transport Protocol | HTTPS
| Frequency | Per user session
| Support Team | Identity & Access Team
| Operational Ownership | Corporate Services
| Monitoring Approach | Sign-in failure rate and IdP availability alerts
|===
